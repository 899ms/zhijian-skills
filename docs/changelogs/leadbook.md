# leadbook Changelog

## 1.0.0 — 2026-07-26

- Establish the first governed public candidate for evidence-backed Chinese business books and white papers.
- Add a standard-library Core path for safe scaffold, merged state sync, WIP export, SVG generation, and three-tier quality checks.
- Prevent unmarked-directory replacement, template leakage, blank-draft false positives, diagram path escape, and hardcoded diagram labels.
- Separate optional WeChat, Xiaohongshu, Kami, image, and PDF providers from the Core workflow.
- Redact Xiaohongshu detail tokens and raw payloads by default, omit IP-location labels, and require explicit non-loopback routing.
- Add deterministic tests and representative evaluation prompts.
- Default portable runs to public-Web research while keeping local and platform-specific providers optional.
- Require concrete URLs for facts, behavior signals, transaction signals, selected authority sources, and used source-map rows.
- Add durable phase checkpoints, automatic PDF page rendering/contact sheets, exhaustive visual-audit validation, and digest-bound gate receipts.
- Move the unfinished reader workbook into templates so a fresh project does not ship a placeholder distribution artifact.
- Keep planned visual assets as warnings at the pre-build draft gate, synchronize visual coverage transactionally, and reject orphaned bibliography tail pages at publish-ready.
