# web-clipper Changelog

## 1.0.0 — 2026-08-04

- Publish the first independently governed Portfolio release.
- Save one public article or a bounded article list as structured Markdown with source metadata.
- Route extraction through static HTML, pinned Defuddle, Jina Reader, optional Metaso, and browser fallbacks.
- Bootstrap Python and a project-local clipping configuration through one wrapper command.
- Reject non-HTTP(S) inputs, project-escaping output paths, and empty batch results.
- Add deterministic parser, output, bootstrap, path-boundary, and dependency-pin tests.
